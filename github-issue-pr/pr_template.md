# Pull Request Template — AksaLoka

```markdown
## Summary

<ringkasan perubahan>

Closes #<issue-number>

## Changes

- <perubahan utama per area/file bila membantu>

## Verification

- `<command>` → <hasil>

## Risks / migration / rollback

- <risiko, kebutuhan migration/deployment, atau langkah rollback; tulis "Tidak ada" bila tidak relevan>
```

Gunakan `Closes` hanya untuk Issue yang selesai sepenuhnya. Untuk pekerjaan parsial, ganti dengan `Refs #<issue-number>` atau `Related to #<issue-number>`.
